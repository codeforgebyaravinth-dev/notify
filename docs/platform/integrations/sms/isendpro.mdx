You can use [iSendPro](https://www.isendpro.com/sms-api.php) to send SMS messages through Notify.

## Getting started

1. Create or log in to your iSendPro account.
2. Copy your **API Key** from the iSendPro API settings.
3. Optionally configure a default sender if your account supports one.

## Creating an iSendPro integration with Notify

1. Visit the [Integrations](https://dashboard.novu.co/integrations?utm_campaign=docs-sms-isendpro) page on Notify.
2. Click **Add a provider**.
3. Locate **iSendPro** under the SMS section and click **Connect**.
4. Enter your:
   - **API Key**
   - **Sender** (optional default from value)
5. Confirm **Active Integration** is on. New integrations start active by default.
6. Click **Create Integration**.

You can now send SMS notifications with iSendPro through Notify.
