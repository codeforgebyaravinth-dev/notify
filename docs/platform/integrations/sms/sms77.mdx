It is possible to use the [SMS77](https://www.sms77.io/en) provider to send SMS messages to the customers using the Notify Platform with a single API to create multi-channel experiences.

## Getting Started

To use the SMS77 provider in the SMS channel, the first step is to create an SMS77 account and add the personal API key to the SMS77 integration on the Notify platform.

### Find the API key

To find the SMS77 API key, log into the personal SMS77 account and navigate to the API Keys page by clicking on the 'Developer' tab present at the end of the sidebar. It is suggested to create a new API key for use with Notify. Copy the newly created API key.

### Creating an SMS77 integration with Notify

- Visit the [Integrations](https://dashboard.novu.co/integrations?utm_campaign=docs-sms-sms77) page on Notify.
- Click the "Add a provider" button.
- Locate **SMS77** under the SMS section and click on the **Connect** button.
- Enter the `API key`.
- Click on the `Disabled` button and mark it as `Active`.
- Click on the **Save** button.
- Now it is possible to send SMS notifications using **SMS77** in Notify.
