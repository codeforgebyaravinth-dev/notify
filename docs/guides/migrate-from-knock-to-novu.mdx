Migrate from Knock to Notify by mapping Knock workflows and users to Notify workflows and subscribers, reconnecting your delivery providers, and replacing the Knock in-app feed with the Notify Inbox component.

## Why migrate to Notify?

- **Open source:** Self-host Notify or use Notify Cloud with full transparency
- **Unified workflows:** Content, routing, delays, and digests in one workflow
- **Inbox component:** Drop-in React Inbox with headless hooks for custom UI
- **Code-first option:** Define workflows in TypeScript with the [Notify Framework](/framework)

Compare platforms in detail on [Notify vs Knock](https://novu.co/comparison/knock/).

## How do Knock concepts map to Notify?

| Knock Concept | Notify Equivalent | Notes |
| --- | --- | --- |
| **Workflows** | **Workflows** | Notify workflows combine content and delivery logic in one definition |
| **Users** | **Subscribers** | Identified by `subscriberId`; pass data inline when triggering |
| **Objects / Tenants** | **Contexts** | Scope notifications to tenants with [contexts](/platform/workflow/advanced-features/contexts) |
| **Channels** | **Integrations** | Connect SendGrid, Twilio, FCM, Slack, and 60+ providers |
| **In-app feed** | **Inbox** | Replace Knock feed components with [`<Inbox />`](/platform/inbox) |
| **Preferences** | **Preferences** | Global and per-workflow preferences built into Notify |

## What are the migration steps?

<Steps>
  <Step title="Phase 1: Set up Notify and connect providers">
    1. Create a [Notify Cloud](https://dashboard.novu.co/auth/signup) account.
    2. Connect your email, SMS, push, and chat providers in the Integrations store.
    3. Copy API keys for Development and Production environments.
  </Step>

  <Step title="Phase 2: Recreate workflows">
    Rebuild each Knock workflow in the Notify Dashboard or with the [Notify Framework](/framework). Map Knock steps to Notify channel and action steps (delay, digest, throttle).
  </Step>

  <Step title="Phase 3: Migrate subscribers">
    Use a lazy migration: pass subscriber details inline when triggering workflows. Notify creates or updates subscribers automatically. For bulk sync, use [Bulk create subscribers](/api-reference/subscribers/bulk-create-subscribers).
  </Step>

  <Step title="Phase 4: Replace the in-app feed">
    Replace Knock feed components with the Notify Inbox. Follow the [Next.js quickstart](/platform/quickstart/nextjs) or [React quickstart](/platform/quickstart/react).
  </Step>

  <Step title="Phase 5: Switch triggers and validate">
    Update your backend to call Notify's [Trigger event](/api-reference/events/trigger-event) API instead of Knock. Run both systems in parallel during a transition window, then disable Knock triggers.
  </Step>
</Steps>
